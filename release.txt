Change log: 
----------

1.6.0 (2025-08-11)
* Main Window: add "Log" tab to see the debug log without blocking the application.
* Live Viewer: fixed image and histogram flipping and other visual artifacts when rapidly resizing.
* Photobleaching command checks stage limits before starting.
* Photobleaching command now includes speed and number of lanes.
* Add leading zeros to multi-lane series acquisition numbering and use AA, AB, ... for more than 26 fields.
* New Z-stack acquisition mode.
* Improved autofocus speed and reliability.
* Detect Cancel button press during laser power adjustment.
* Autofocus failure is a warning in log file, but allows series acquisition to continue.
* Live Viewer: fixed ghost images in background pane in previous version.
* Added logging of steps in series acquisition.
* Use C++/OpenCV module for particle counting to reduce computational load, avoid requirement for MATLAB, and reduce startup time.

1.5.7 (2025-07-21)
* Fix incorrect stage limit calculation before movie series.
* Block photobleach command when light path is set to eyepieces for safety.
* Stage: Save microscope Z position in TIFF metadata (Ti2 stand only).
* Kinetix: always use default scan mode for autofocus. Speed mode has correlation properties that interfere with focus score metric.
* Live viewer: clamp color scale range to selected bitrate.
* Live viewer: fix image disappearing when repeatedly resizing window.
* Laser: allow initialization to continue when a laser device is not found.

1.5.6 (2025-05-05)
* New multi-lane series movie acquisition mode with "..._A01.tif" numbering (letters are fields, numbers are lanes).
* Add underscore before automatic movie numbering: "..._001.tif".
* Autofocus uses only the center quadrant for objective function.
* Increase autofocus step delay to avoid rare failure from dropped frames.
* Check stage limits and file path before movie series starts, moving all checks out of Main Window.
* Enable live configuration of stage step size in advanced tab.
* Fixed issue #5 Photometrics frame shearing in TIFF files.

1.5.5 (2024-11-19)
* Time-lapse recording: viewer now displays frames as fast as possible instead of skipping some.
* Autofocus: fixed race condition involving global variable that resulted in unnecessary stage movements.
* Autofocus: revert to previous Z position if any frames were missed during Z stack, even if Gaussian fit of scores succeeds.
* Autofocus: increase Z stage settling time to 1s to improve accuracy.
* Autofocus: failure returns Z stage to previous position and automatically cancels movie series.
* Power meter: reduce polling rate to 2/s to reduce resource demands and stuttering, especially with NI-DAQ and Thorlabs polarizer.
* Nikon stand: un-escape objective on startup.

1.5.4 (2024-10-16)
- Nikon Ti2: automatically escape objective on shutdown.
- Photometrics Kinetix: use speed (12-bit) mode by default.
- Photometrics: block special characters in filenames that cause streaming to fail.
- Hamamatsu: fixed photonsPerCount metadata field with incorrect values.
- Cameras: increase buffer size to 1000 frames to avoid dropped frames.
- Cameras: more accurate test of available disk space before recording.
- NI DAQ: send exactly the requested number of camera trigger pulses..
- Improved error checking and other bugfixes.

1.5.3 (2024-9-11)
- Use JSON for configuration files (avoids errors when using a config file from a previous version).
- Preliminary support for Cobolt lasers
- Cameras: use internal triggering if no sync device installed.
- Hamamatsu: increase buffer size to avoid dropped frames.
- Hamamatsu: examine frame timestamps to detect missed triggers or dropped frames.
- Photometrics: read import tips text file when converting to tiff to avoid rare errors.
- Improved error checking and other bugfixes.

1.5.2 (2024-8-27)
- Automatically set laser power to zero on startup for safety.
- Hamamatsu cameras: read photoelectron/ADU conversion factors from camera instead of configuration.
- Viewer: double-click resets zoom.
- Main Window: reduce flicker in stage position indicator.
- Improved error checking and other bugfixes.

1.5.1 (2024-8-16)
- Support for Arduino triggering device. Provides much better time resolution.
- Experimental support for Photometrics Kinetix cameras.
- Experimental support for Andor EMCCD cameras (SDK 2).
- ADU to photoelectron conversion factor is now an array (one per readout mode).
- Main Window: added controls for camera readout mode and binning in Advanced tab.
- Live Viewer: status bar shows count of saturated pixels (important for low bitrate modes).
- Lasers: automatically home PRM1Z8 on startup if not already homed.
- Camera: save correct pixel size to file, assuming 60x mag.
- Hamamatsu: increase jitter parameter to avoid rare missed frames.
- Hamamatsu: retrieve sensor size and readout parameters from driver to make it easier to support new cameras.
- dcimg2tiff: refactor for modern C++ to avoid obscure memory bugs.
- Viewer: synchronization frame data b/t cameras.
- Update project to LabVIEW 2023 (SP3) from 2018 (SP1).
- Improved support for adding new devices (dynamic dispatch).
- Compiled version does not require all device drivers to be installed.
- Improved error checking and reporting that does not bring down the whole application.
- Many other bug fixes and performance improvements.
