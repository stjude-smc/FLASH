Change log: 
----------

1.5.3 (2024-9-11)
- Use JSON for configuration files (avoids errors when using a config file from a previous version).
- Preliminary support for Cobolt lasers
- Cameras: use internal triggering if no sync device installed.
- Hamamatsu: increase buffer size to avoid dropped frames.
- Hamamatsu: examine frame timestamps to detect missed triggers or dropped frames.

1.5.2 (2024-8-27)
- Automatically set laser power to zero on startup for safety.
- Hamamatsu cameras: read photoelectron/ADU conversion factors from camera instead of configuration.
- Viewer: double-click resets zoom.
- Main Window: reduce flicker in stage position indicator.
- Improved error checking and other bugfixes.

1.5.1 (2024-8-16)
- Support for Arduino triggering device. Provides much better time resolution.
- Experimental support for Photometrics Kinetix cameras.
- Experimental support for Andor EMCCD cameras (SDK 2).
- ADU to photoelectron conversion factor is now an array (one per readout mode).
- Main Window: added controls for camera readout mode and binning in Advanced tab.
- Live Viewer: status bar shows count of saturated pixels (important for low bitrate modes).
- Lasers: automatically home PRM1Z8 on startup if not already homed.
- Camera: save correct pixel size to file, assuming 60x mag.
- Hamamatsu: increase jitter parameter to avoid rare missed frames.
- Hamamatsu: retrieve sensor size and readout parameters from driver to make it easier to support new cameras.
- dcimg2tiff: refactor for modern C++ to avoid obscure memory bugs.
- Viewer: synchronization frame data b/t cameras.
- Update project to LabVIEW 2023 (SP3) from 2018 (SP1).
- Improved support for adding new devices (dynamic dispatch).
- Compiled version does not require all device drivers to be installed.
- Improved error checking and reporting that does not bring down the whole application.
- Many other bug fixes and performance improvements.
