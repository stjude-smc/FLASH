Change log: version 1.0
----------

This version is a fork of Manuel Juette's version 0.6.1b. Manuel made several versions
  after this, but none were stable enough to use as a foundation. He may have made a
  version 1.0, but that is not the same as this one.

* User Interface:

    - Much faster rendering of the live window reduces lag/stutter, especially with four cameras.

	- More graceful error handling, for example with invalid configuration files.

	- Simplified block diagrams of Live Viewer and Main Window.

	- Live Viewer: add timeout to prevent freezing if data camera never received.

	- Disable acquisition controls during streaming to prevent file saving errors.

	- Prevent Flash Gordon splash screen from hiding "Choose Configuration" diaglog.

	- Main Window status bar for background .tif movie saving (conversion from .dcimg).

	- Main Window: show correct number of veritcal lines for specified time resolution.

	- Live Viewer: image flipping still occurs but 

* Cameras:

	- Use Hamamatsu video capture library version 4.4. Tested with DCAM version 18.12.5685.
	    Required for properly supporting newer Fusion cameras.

	- Fix crash: number of lines must be divisible by 8.

	- Fix crash when closing Flash Gordon (trying to close camera handle after deleted).

	- Fix various triggering issues, especially for sub-ms recordings.

	- Automatically choose optimal readout mode for a given camera and time resolution.

	- Fix variable delay between end of stream acquisition and .tif file conversion caused by
	    pile-up of "Get Most Recent Frame" messages with short refresh time.

* Stage:

	- Support for Ti2 stage movement. Allow "Disabled" as a valid microscope configuration.
	    Stage moves in 100 um increments to avoid freezing control pad and allow stopping movement early.

	- Disable stage "Move Home" unless user has pressed "Set Home" first to prevent undefined behavior.

	- If Ti2 stage not detected, give an error instead of silently failing or crashing.

	- Disable Ti2 control pad joystick while photobleaching to prevent erratic behavior.

	- Detect when stage reaches hardware limit, show a warning, and gracefully recovery.


* Lasers:

	- LaserQuantum: if user tries to set power for a laser not configured, give a warning rather than crash.

	- Add support for rapid laser power tuning with a rotating polarizer (Thorlabs PRM1Z8).

	- LaserQuantum: include cases for supported lasers including OBIS (RS232) and "Disabled".
	    This should be renamed to "Virtual Laser" in the future.

* Fluidics:

	- Early implementation of Cetoni device (not enabled yet).

* BinaryTIFF:

	- Support for new .dcimg file format with newer DCAM/cameras.

	- "Rescue Raw Data" no longer tries to read proprietary .dcimg fields for image size,
	    which changes between library versions. Instead, get parameters from "Max Lines.vi".

	- Create TiffWriter class to convert .dcimg to .tif files in the backrgound.
	    This allows user to Show Live or start next acquisition without delay.



Known issues:
----------

- Main window stage "STOP" button does not appear to work for Ti2.

- Changing time resolution or other camera settings during live display will cause
   pixel correction to be turned off unexpectedly.

- The progress bar for file saving (conversion to .tif) can have erratic behavior or
   stall if the user either acquires a new movies with a different number of frames
   while the previous one is saving or cancels the acquisition early. This does not
   affect the saved files, only the status bar appearance.

- Errors in Actors only give a generic Actor Framework message. 

- Live Viewer color map bar is often reversed and scale limits can go be out of range.




Testing platforms verified to work:
----------
 - Windows 10 Enterprise (20H2; build 19042.1526) 64-bit
 - Hamamatsu HVC 4.4 and DCAM 18.12.5685
 - Hamamatsu Fusion (C14440-20UP) with USB 3.0 interface.
 - Hamamatsu Flash 4.0v2 (C11440-22CU) with CoaXPress cards. Flash v3 probably also works.
 - Nikon Ti2 stand with build-in stage and filter turret.
 - Newport ESP301 stage driver
 - LaserQuantum Ciel 473nm and Opus 532 lasers
 - Thorlabs PRM1Z8 rotation stage for laser attenuation polarizer.
