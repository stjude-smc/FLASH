Change log: 
----------

1.5.0 (2024-7-11) -- testing branch
- Experimental support for Photometrics Kinetix cameras. Other Photometrics cameras may work but are untested. See documentation for limitations and known bugs.
- Experimental support for Andor EMCCD cameras (SDK 2).
- ADU to photoelectron conversion factor is now an array, with one value per camera readout mode; can't assume they are all the same.
- Main Window: added controls for camera readout mode and binning in Advanced tab.
- Live Viewer: status bar shows count of saturated pixles (important for low bitrate modes).
- Fluidics trigger line can be adjusted in configuration file.
- Update project to LabVIEW 2023 (SP3) from 2018 (SP1).
- Improved error handling.
- Avoid possible deadlock conditions when waiting for cameras to be ready for acquisition.
